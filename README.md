## 🌟 Overview & Architecture

**AetherVault Omni Edition (Tele Drive)** is an enterprise-grade, zero-knowledge personal cloud storage and file management Android app built with **Kotlin** and **Jetpack Compose**. Designed and engineered by **Ayush Mondal (AJPM)**, it turns your private Telegram Channel and Telegram Bot API into an infinite, fast, serverless cloud storage vault without monthly subscription fees or third-party cloud data harvesting.

### Core Architectural Features
1. **On-Device AES-256-GCM Encryption:** Every file (photo, video, document, archive, or code snippet) is locally encrypted on-device with a unique cryptographic key before being chunked into 19MB Telegram messages.
2. **Telegram Multi-Bot Swarm Engine:** Distributes upload and download chunk traffic across multiple Telegram bots to maximize bandwidth and prevent API rate-limiting.
3. **Telegram Chat & Cloud History Synchronization:**
   - Synchronize your private Telegram channel's pre-existing messages, text snippets, and files directly into your local database.
   - Send live messages and snippets to your private channel directly from the app.
   - Built-in one-tap 120Hz smooth sync button and full message search.
4. **Google Material Design 3 (Material You) Interface:**
   - Modeled after the modern Google Drive and Google Photos interfaces.
   - Authentic pill-shaped top search bar with hamburger drawer menu and Telegram bot health indicator.
   - M3 4-item bottom navigation bar with fluid animated selection pills.
   - 2-column bento folder and media grid with square 1:1 previews and cloud sync badges.
   - Dual floating action buttons (secondary lilac camera FAB + primary blue upload FAB).
   - Clean, tonal empty-state vector illustrations for zero-item states.
