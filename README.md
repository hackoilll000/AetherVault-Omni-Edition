## 🚀 Major Systems & Features Matrix

### 1. 🎨 A-Z Customization Studio & Theme Engine
- **9 Premium Theme Presets**: Material You Monet, Obsidian Gold, Titanium Ice, Pure AMOLED, High Contrast, Alabaster Clean, Frosted Glass, Nothing Dot-Matrix, and Custom User Palette.
- **Custom Color Palette Editor**: Interactive HEX / RGB color inputs for Primary, Secondary, Tertiary, Surface, Background, Card, Navigation, and Code Editor colors.
- **WCAG AA Contrast Validator**: Live relative luminance contrast ratio calculation (`AppearancePreferences.calculateContrastRatio()`) with automated warnings for low contrast.
- **Typography & Font Scaling**: Custom Monospace, Serif, Sans-Serif font modes with 0.85x to 1.25x fluid font scaling.
- **Motion & Sound Control**: Reduced motion toggles, animation speed profiles (Off, Slow, Normal, Fast), and haptic intensity controls.
- **JSON Profile Export & Import**: One-tap versioned JSON customization profile backup and import.

### 2. 🐍 Self-Hosted Python Bot Studio & Termux Deployer
- **Zero Developer-Server Backend**: 100% user-owned bot execution architecture.
- **Bot Starter Templates**: Pre-configured templates for Echo Bot, FAQ Bot, Group Moderation Bot, Scheduled Reminder Bot, Gemini AI Assistant Bot, and Webhook Automation Bot.
- **Built-In Python Editor**: Code editor with line numbers, syntax validator (`BotProjectManager.validatePythonScript()`), search/replace, and `.env` environment variables manager.
- **Termux Deployment Manager**: Automatic bash script generator (`termux_start_bot.sh`), requirements file generator (`requirements.txt`), and live log console with automatic credential redaction.
- **AI & Database Connectors**: Integrations for user-provided Gemini/OpenAI API credentials, PostgreSQL/MySQL/SQLite connection builders, read-only defaults, and parameterized query security.

### 3. 📦 Cloud-Backed Artifact Storage Engine
- **Versioned Artifact Manifests**: Full JSON spec (`ArtifactManifest`) with metadata and SHA-256 per-chunk checksums.
- **Safe Staging Engine**: `ArtifactStagingEngine` featuring path-traversal safeguards, free disk space reserve checks, and atomic directory promotion.
- **Save-State Sync Engine**: `SaveStateSyncEngine` separating immutable binaries from mutable user save state, with encrypted snapshot deltas and conflict resolution policies (`PRESERVE_LOCAL`, `OVERWRITE_REMOTE`, `FAIL_SAFE_ABORT`).
- **LRU Cache & Disk Quota Manager**: `ArtifactCacheManager` enforcing configurable disk quotas, 100 MB free reserve, and active process leases to prevent evicting active application files.
- **Desktop Launcher & Virtualization Spec**: `DesktopProcessLauncher` for process supervision and `VirtualFilesystemSpec` for WinFsp virtual drive offset lookups.

### 4. 🔒 Multi-Bot Telegram Cloud Storage & Encryption
- **AES-256-GCM Encryption**: On-device KeyStore encryption with unique per-chunk IV offsets.
- **Multi-Bot Swarm Engine**: Traffic distribution across multiple Telegram bots with rate-limit handling on `FLOOD_WAIT_X`.
- **TeleDrop Channel History Sync**: Live channel message search, snippet sharing, and 120Hz smooth offline synchronization.

## 🛠️ Building From Source

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hackoilll000/AetherVault-Omni-Edition.git
   cd AetherVault-Omni-Edition
   ```
2. **Compile the Debug APK:**
   ```bash
   gradle assembleDebug
   ```
3. **Run Unit & Robolectric Tests:**
   ```bash
   gradle :app:testDebugUnitTest
   ```
