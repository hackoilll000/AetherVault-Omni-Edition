AetherVault Omni Edition is a modern, zero-knowledge encrypted cloud storage file manager for Android that transforms your private Telegram server into an ultra-secure personal cloud vault.

KEY FEATURES:

1. ZERO-KNOWLEDGE CRYPTOGRAPHY:
Every file is encrypted on-device using AES-256-GCM authenticated encryption and split deterministically into 19 MB frames. Master keys are derived locally via salted PBKDF2-HMAC-SHA256 (10,000 iterations). Plaintext filenames, contents, and metadata are never visible to Telegram servers.

2. PERSISTENT LOGIN & FLEXIBLE SECURITY POLICIES:
Keep session active across app restarts with customizable lock policies:
- Stay Unlocked (Persistent Login)
- Lock After Inactivity (15 Minutes)
- Always Require Password

3. STEALTH DECOY VAULT & ISOLATED SESSIONS:
Set an optional stealth decoy PIN. Unlocking with the decoy PIN switches the Room database dynamically to an isolated storage vault, ensuring zero metadata leakage from your primary vault.

4. MULTI-BOT SWARM ENGINE & HIGH-SPEED SYNCHRONIZATION:
Connect multiple Telegram bot workers to parallelize chunk uploads and downloads, drastically accelerating transfer throughput while respecting Telegram Bot API rate limits.

5. FAST LOCAL OFFLINE SEARCH:
Instant, zero-latency local search across your file library with category chips (Photos, Videos, Audio, Documents, Archives), sorting rules, and persistent recent queries.

6. VERIFIED STORAGE METRICS & DUPLICATE AUDITOR:
View detailed analytics on your cloud storage, category size breakdowns, largest files, and duplicate file candidate detection.

7. MATERIAL DESIGN 3 & APPEARANCE STUDIO:
Polished Material 3 user interface featuring high-contrast light and dark modes, AMOLED black theme, WCAG AA compliance, and 5 custom aesthetic presets.
